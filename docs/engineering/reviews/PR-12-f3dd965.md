## Cause (src/lib/echo/intentResolver.ts)

`explicitCancellation` and `restraintFrame` are fixed regex lists:
`don't|do not|never` need the apostrophe/space form (`dont` fails);
Arabic/Franco lists cover specific stems only; `correctionFrame` treats `لا`,
`مش`, `no` as a correction *before* action routing and yields a
focus-update proposal. Negative markers are not applied as a scope over the
detected action verb.

## Recommended follow-ups (proposed tasks, not edits to PR #12)

1. Negation scope: any negator within N tokens before/after an action verb
   (`dont`, `no need`, `hold off`, `متـ…ش` circumfix, `مش عايز`, `لا`) produces
   CANCEL/RESTRAINT before correction and action routing.
2. Add regression tests for cases 1–10 (EN/AR/Franco), including a positive
   control for each (`send it`, `ابعته`).
3. Decline-or-clarify outbound contact verbs not currently detected
   (`call`, `اتصل`, `كلمه`, `ekteb`).
4. Natively run WebKit evidence is in CI run 35817023392 only; re-confirm it
   after any new push (this verdict is pinned to f3dd965).
