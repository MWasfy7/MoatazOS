# SalesOS Diagnostic Handoff

This package defines the bounded input and review process for a customer-funded or customer-authorized SalesOS diagnostic.

- [Supported CRM CSV schema](./supported-crm-schema.md)
- [WhatsApp export instructions](./whatsapp-export-instructions.md)
- [Sanitized demo dataset template](./sanitized-demo-dataset-template.csv)
- [One-page diagnostic workflow](./workflow.md)
- [Data and privacy requirements](./data-privacy-requirements.md)

The application remains preview-only. It does not connect to a CRM, persist imported customer data, contact a lead, write to a source system, or claim conversion causality.
